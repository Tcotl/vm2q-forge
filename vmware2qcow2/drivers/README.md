# Optional virtio-win assets

The converter has the version catalog and selection rules built in. Place the
matching ISO files in this directory for automatic discovery:

```text
virtio-win-0.1.173-9.iso
virtio-win-0.1.285-1.iso
```

The ISO files are kept outside source control. They can also be supplied with
`--virtio-win-old`, `--virtio-win-new`, or the backward-compatible
`--driver-iso` option.
